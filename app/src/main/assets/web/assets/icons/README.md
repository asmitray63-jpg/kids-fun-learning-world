# App Icon Suggestions

Suggested Play Store icon direction:

- smiling yellow reward star in the center
- sky blue background with small ABC / 123 shapes
- high contrast edges for small launcher sizes
- no text inside the icon

Export final icons with Android Studio Image Asset:

- foreground: mascot/star illustration
- background: `#67D7FF` or a soft yellow-to-sky gradient
- adaptive icon safe zone: keep important artwork inside the center 66%
